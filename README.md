# 🎯 Internship Eligibility & Career Recommender

A Streamlit-based Python application that checks basic internship eligibility
and recommends suitable career fields based on a user's:

- CGPA
- Academic Branch
- Graduation Year
- Skills
- Experience
- Interests

## 🚀 Features

- Internship eligibility checker
- Career field recommendation
- Career match percentage
- Top 3 career matches
- Matching skills
- Missing skills
- Personalized career roadmap
- Profile summary
- Interactive charts
- Professional Streamlit UI

## 💻 Technologies Used

- Python
- Streamlit
- Pandas
